# StyleHub - Laravel E-Commerce Website

StyleHub is an English e-commerce web application developed with Laravel.

The project includes product management, shopping cart, checkout, order management, authentication, and role-based admin access.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- Laravel
- MySQL
- Laravel Breeze
- Git & GitHub

## Main Features

### Public Website

- Homepage
- Featured categories
- Product listing
- Product detail page
- Add to cart
- Shopping cart
- Update cart quantity
- Remove product from cart
- Checkout page
- Order success page

### Admin Panel

- Admin product list
- Create product
- Edit product
- Delete product
- Show product details
- Admin order list
- Show order details
- Update order status

### Authentication and Authorization

- Login system
- Register system
- Admin role system
- Role-based access control
- Normal users cannot access admin pages
- Admin users can manage products and orders

## Database Tables

The project uses the following main tables:

- users
- roles
- role_user
- categories
- products
- carts
- orders
- order_items
